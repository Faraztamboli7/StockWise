# 📊 StockWise

**StockWise** is a lightweight Python CLI tool that lets you fetch real-time stock data and visualize historical price trends using Yahoo Finance.

---

## 🚀 Features

- 🔎 Get real-time stock prices and company info
- 📈 View financial metrics like P/E Ratio, Market Cap, 52-week high/low
- 🕒 Plot 6-month historical closing price charts
- 🌍 Works for Indian and global stocks (e.g., `AAPL`, `INFY.NS`)
